# TIME.mk sources

TIME.mk aggregates **113 sources** in 3 groups: 48 news, 55 portals and 10 sports. Captured 2026-11-14 from [time.mk/s/all](https://time.mk/s/all).

- TIME.mk lists only names and its own slugs. Its source pages (`time.mk/s/<slug>`) don't show the outlet's domain, so domains and RSS feeds need to be looked up separately.
- Seer v0's 15–20 sources should come from the News group.
- The same data is in [`timemk-sources.csv`](timemk-sources.csv).
